\subsection{数据来源与口径}

本文使用的原始数据来自附件1与附件2。附件1提供某一天不同时间的电价（元/kWh）、小区负载（kW）与光伏发电预测功率（kW），共144个10分钟时段；附件2提供2025年1月1日至12月31日每天的小区负载（kW）与光伏发电实际功率（kW），每天同样为144个10分钟时段。储能参数见附录1，相关数据由附件5提供。

附件中的时刻均为时段终点，即$00{:}10$表示$00{:}00$--$00{:}10$，$0{:}00{+}1$表示当天$24{:}00$；时段长$\Delta t=10$ min $=1/6$ h，电量与功率满足$E=P\Delta t$。图~\ref{fig:data_q1_profile}给出了附件1的电价、负载与光伏预测功率曲线，电价呈明显的早晚双峰结构，负载与光伏的峰谷时段与电价结构共同决定了储能套利与购电策略的可行空间。

\subsection{预处理规则}

为保证问题一与问题二口径一致，按以下规则处理原始数据。

\begin{enumerate}
  \item \textbf{时间对齐}：将附件中的时刻统一解析为“时段终点分钟数”，$00{:}10\to10$、$0{:}00{+}1\to1440$，并按物理区间改写时间标签（$00{:}00$--$00{:}10$、$\dots$、$23{:}50$--$24{:}00$），避免官方模板相对真实时段错后10分钟。
  \item \textbf{单位统一}：功率统一为kW、电价统一为元/kWh，电量按$E=P\Delta t$换算为kWh。
  \item \textbf{特征构造}：为问题二的滚动预测构造11个特征——时刻编号$slot$、星期$dow$、月份$month$、年内日序$doy$，以及前1/2/7天同刻值$lag_{1d},lag_{2d},lag_{7d}$与过去3/7/30天同刻均值、过去7天同刻标准差$mean_{3d},mean_{7d},mean_{30d},std_{7d}$。所有特征只使用预测日$D$之前的历史数据，避免未来信息泄漏。
  \item \textbf{光伏夜间置零}：对附件2中历史同刻恒为0的43个夜间时段，预测值强制置0。
  \item \textbf{残差分位保守修正}：用$day<D$的历史预测残差，对负荷取$q_{L}=0.8$高分位、对光伏取$q_{PV}=0.2$低分位进行修正，使净负荷预测更保守，以降低紧急购电风险。
  \item \textbf{储能口径}：问题二以2025年2月1日$0{:}00$储电量$6000$ kWh为初值，1月数据仅用于预报训练与残差分位统计；2月1日之后跨日传递实际运行末值，储电量始终约束在$[1200,10800]$ kWh。
\end{enumerate}

清洗后的数据与处理脚本在支撑材料中保留，正文所引用的全部数字均来自可复现的清洗与求解流程。
