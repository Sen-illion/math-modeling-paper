\section{问题四：实时波动电价下的购电策略}

\subsection{问题分析}

问题一至问题三均假设外网电价为已知或按附件~1 固定，而问题四要求考虑\textbf{外网电价实时波动}：购电决策时只能依据历史电价预测当天电价，结算则按附件~4 的真实电价。需要重新求解问题二与问题三，分别给出波动电价下的全年日前计划（Q4-2）与日内滚动调整（Q4-3）。

本问继承问题二的决策变量、储能约束、净负载分位与 $\rho$ 回放，继承问题三的 $48$ 小时展望与锁死段分位；新机制只有电价：决策用当天 $0{:}00$ 的预测价 $\hat p_0$，结算用附件~4 真值 $\pi_t$。因此不重做探索性分析，也不改写前两问的线性规划，只厘清信息集与口径，再给出电价预测，最后把已冻结的调度结构放到附件~4 世界上回测。

\begin{enumerate}[label=(\arabic*)]
  \item \textbf{信息集}：决策日 $0{:}00$ 只能使用附件~1、附件~2、附件~3 及附件~4 中该日之前的价格、负载、光伏；$6/12/18$ 点可更新当天已发生的负载与光伏，但\textbf{电价仍锁当天 $0{:}00$ 的 $\hat p_0$}，不使用当日或未来真实电价。
  \item \textbf{结算口径}：附件~4 真值 $\pi_t$；计划高于调整（少买）按 $0.5\pi_t$、低于（多买）按 $1.5\pi_t$、供电缺口按 $5\pi_t$ 紧急购电。
  \item \textbf{可行域}：储能 $[1200,10800]$ kWh、接口 $5000$ kW、效率口径同模型假设、不可倒送、允许弃光，与问题二、三完全一致。
  \item \textbf{情景分支}：Q4-2 对照固定分量分位 $q{=}0.8$；Q4-3 对照不调整的 N0 与带选择门的 M0L。两个子问题并列报告，不合成一个「问题四最优」。
\end{enumerate}

决策始终用预测电价，回测与结算始终用附件~4 真值，二者不得对调。调度参数从附件~1 世界原样搬运，不在 $2$--$12$ 月正式窗上按总费用反调。

\subsection{模型建立}

\subsubsection{日前电价预测}

记 $\hat p_0$ 为决策日 $0{:}00$ 对当天各时段电价的预测。电价有稳定的日内形状和星期效应，且必须在 $0{:}00$ 完成、不能看见当天真值，故采用\textbf{因果三层扩展模型}，而不另建复杂时序模型：
\begin{equation}
  \hat p_0 = b + \Delta_{\mathrm{week}} + \Delta_{\mathrm{recent}},
\end{equation}
其中 $b$ 为历史同日同时段电价的扩展均值，$\Delta_{\mathrm{week}}$ 为同一星期几的历史残差均值，$\Delta_{\mathrm{recent}}$ 为最近 $7$ 日残差的等权均值。三层样本都只用决策日之前的数据；$2025$ 年 $1$ 月 $1$ 日的基项 $b$ 仅用附件~1 冷启动，之后随真实电价滚动扩展。后文 Oracle 对照显示，即便把决策电价换成当天真值，费用也只再降约 $0.57\%$，说明这一分解已接近可用上界。

\subsubsection{波动电价下的调度模型}

调度结构与问题二、问题三同构，仅替换价格输入：

\begin{itemize}
  \item \textbf{Q4-2（对应问题二）}：沿用问题二正式日前链——因果扩展 XGBoost 负载、$7$ 日同刻光伏、净负载 $0.8$ 分位、日前 LP、日末硬约束 $2400$\,kWh、日内 $\rho{=}0.625$ 保护回放、锁死 $G_t$、缺口按 $5$ 倍紧急购电。决策电价为 $\hat p_0$，结算电价为附件~4 真值。
  \item \textbf{Q4-3（对应问题三）}：沿用问题三正式 \texttt{LA}——$48$ 小时展望、净负载分位签合同（锁死段 $q=0.60$、可改段与次日 $q=0.50$）、光伏插值起点取实测；$6/12/18$ 点只更新光伏与负载、\textbf{电价锁当天 $\hat p_0$}，偏差按少买 $0.5$ 倍、多买 $1.5$ 倍、紧急 $5$ 倍结算。锁死段取 $0.60$ 是为与问题三正式口径对齐，而不是在附件~4 世界上重选更省的分位。
\end{itemize}

两个子问题仍用 PuLP 调用 CBC 求解日前或滚动线性规划，实例均返回 Optimal。差异只来自电价环境与 $\hat p_0$，便于把费用变化归因于波动电价，而不是模型改动。

\subsection{模型检验}

\subsubsection{基线对照}

在附件~4 世界上，Q4-2 的净分位 $+\rho$ 优于固定 $q=0.8$（省 $0.46\%$），Q4-3 的 LA 优于不调整的 N0 与选择门 M0L（分别省 $12.42\%$ 与 $5.57\%$），与问题二、问题三在固定电价世界上的排序一致。策略优劣对电价环境是稳健的；参数并未在正式窗上重选，Q4-3 锁死段取 $q=0.60$ 是为与问题三对齐——相对曾试过的 $q=0.65$，全年约贵 $1.3$ 万元，这是方法一致的代价，而不是求解失败。

\subsubsection{电价预测的贡献（Oracle 诊断）}

为分离「电价预测误差」与「电价波动环境」，做 Oracle 对照：决策若使用当天真实电价、结算仍用附件~4 真值，则 hat0 相对 Oracle 仅高约 $0.57\%$。图~\ref{fig:q4_oracle} 把该分解画成瀑布图。\textbf{诊断口径}为 Q4-2 的固定 $q{=}0.8$ 方案与 Q4-3 的 M1，不是表~\ref{tab:q4_all} 的正式净分位 / LA；该诊断未按正式策略重跑。

由图~\ref{fig:q4_oracle} 可见：以附件~1 典型日电价为起点，真实电价环境把 Oracle 成本抬高约 $4.60\%$（Q4-2 固定分位）与 $4.67\%$（Q4-3 M1）；在此之上，负荷、光伏与电价预测误差再抬 $0.57\%$ 与 $0.59\%$。环境间隙约占合计偏差的九成。因此，Q4-2 相对问题二高出的约 $71.8$ 万元，主要不是 $\hat p_0$ 没预测准，而是附件~4 的结算环境收窄了套利空间；三层扩展预测已经足够接近「看见当天真电价」的上界。

\subsubsection{约束与泄漏门禁}

两个子问题全年 $334$ 天均通过 SOC 盒约束 $[1200,10800]$ 与接口功率校验；价格泄漏检查为 $0$（决策从未使用当日真实电价），调度约束与结算均通过独立重算，结果文件与表~\ref{tab:q4_all}、表~\ref{tab:q4_dates} 数字一致。
