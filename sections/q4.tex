\section{问题四：实时波动电价下的购电策略}

\subsection{问题分析}

问题一至问题三均假设外网电价为已知或按附件~1 固定，而问题四要求考虑\textbf{外网电价实时波动}的场景：购电决策时只能依据历史电价预测当天电价，结算则按附件~4 的真实电价。需要重新求解问题二与问题三，即分别给出波动电价下的全年日前计划（Q4-2）与日内滚动调整（Q4-3）。

本题的关键在于两点：其一，\textbf{决策电价与结算电价分离}——决策用当天 $0{:}00$ 的预测价 $\hat p_0$，结算用附件~4 真值 $\pi_t$；其二，\textbf{调度结构尽量复用问题二、问题三已冻结的策略}，只替换价格输入，从而保证四问之间的口径一致、可对照。因此本题不重做探索性分析，先厘清信息集与口径，再给出电价预测模型，最后套用 Q2/Q3 的调度模型在附件~4 世界上回测。

\begin{enumerate}[label=(\arabic*)]
  \item \textbf{信息集}：决策日 $0{:}00$ 只能使用附件~1、附件~2、附件~3 及附件~4 中决策日之前的价格、负载、光伏数据；$6/12/18$ 点可更新当天已发生的负载与光伏，但\textbf{电价仍锁当天 $0{:}00$ 的 $\hat p_0$}，不使用未来真实电价。
  \item \textbf{结算口径}：附件~4 真值 $\pi_t$；计划购电量高于调整购电量（少买）按 $0.5\pi_t$ 结算、低于（多买）按 $1.5\pi_t$、供电缺口按 $5\pi_t$ 紧急购电。
  \item \textbf{可行域}：储能 $[1200,10800]$ kWh、接口 $5000$ kW、效率 $0.9$、不可倒送、允许弃光，与问题二、三完全一致。
\end{enumerate}

\subsection{模型建立}

\subsubsection{日前电价预测}

记 $\hat p_0$ 为决策日 $0{:}00$ 对当天各时段电价的预测，采用\textbf{因果三层扩展模型}（expanding）：
\begin{equation}
  \hat p_0 = b + \Delta_{\mathrm{week}} + \Delta_{\mathrm{recent}},
\end{equation}
其中 $b$ 为历史同日同时段电价的扩展均值，$\Delta_{\mathrm{week}}$ 为同一星期几的历史残差均值，$\Delta_{\mathrm{recent}}$ 为最近 $7$ 日残差的等权均值（$\rho=1.0$）。三层的样本都只用决策日之前的数据，保证因果性；$2025$ 年 $1$ 月 $1$ 日的基项 $b$ 仅用附件~1 冷启动，之后随真实电价滚动扩展。该模型把电价分解为“长期同刻均值 $+$ 周内效应 $+$ 近期漂移”，结构简单、无未来信息泄漏。

\subsubsection{波动电价下的调度模型}

调度结构直接继承问题二、问题三的正式策略，仅把决策电价替换为 $\hat p_0$、结算电价替换为附件~4 真值：

\begin{itemize}
  \item \textbf{Q4-2（对应问题二）}：沿用问题二的 \texttt{D\_pv7d\_adaptive}——负载用因果扩展 XGBoost、光伏用 $7$ 日同刻均值，以历史残差分位数构造\textbf{自适应保守裕度}，$0{:}00$ 求解日前 LP 并锁定合同，缺口按 $5$ 倍紧急购电。
  \item \textbf{Q4-3（对应问题三）}：沿用问题三的 \texttt{LA}——$48$ 小时展望、净负载分位签合同（锁死段 $q=0.65$、可改段与次日 $q=0.50$）、光伏插值起点取实测；$6/12/18$ 点只更新光伏与负载、\textbf{电价锁当天 $\hat p_0$}，偏差按少买 $0.5$ 倍、多买 $1.5$ 倍、紧急 $5$ 倍结算。
\end{itemize}

这样两个子问题的调度逻辑与问题二、三完全同构，差异仅来自电价环境与价格预测，便于把费用变化归因于“电价波动”而非模型改动。

\subsection{模型检验}

\subsubsection{基线对照}

在附件~4 世界上，Q4-2 的自适应裕度优于固定 $q=0.8$（省 $0.47\%$），Q4-3 的 LA 优于不调整的 N0 与 $24$ h$+\beta\sigma$ 的 M1（分别省 $11.40\%$ 与 $1.73\%$），与问题二、问题三在同口径下的结论一致，说明策略的优劣对电价环境稳健。

\subsubsection{电价预测的贡献（Oracle 诊断）}

为分离“电价预测误差”与“电价波动环境”的影响，做 Oracle 对照：决策若使用当天真实电价、结算仍用附件~4 真值，则 Q4-2 的 \texttt{hat0} 相对 Oracle 仅高约 $0.57\%$。这说明费用相对附件~1 世界（问题二 $13\,697\,499.17$ 元）的跳升主要来自附件~4 的波动电价环境本身，而非 $\hat p_0$ 的预测误差，三层扩展电价预测已足够接近可用上界。

\subsubsection{约束与泄漏门禁}

两个子问题全年 $334$ 天均通过 SOC 盒约束 $[1200,10800]$ 与接口功率校验；价格泄漏检查为 $0$（决策从未使用当日真实电价），调度约束与结算均通过独立重算，结果文件与论文数字一致。
