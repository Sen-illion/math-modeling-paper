\section{问题一：确定性模型}

\subsection{问题分析}

问题一要求在已知当天电价、小区负载与光伏发电预测功率的条件下，于每天 $0{:}00$ 制定微网当天的计划购电策略：微网供给不低于小区负载，储能设备在 $0{:}00$ 与 $24{:}00$ 的储电量相同，并最小化全天购电费用。这是一个单日、确定性、多时段的能量调度问题，可建模为线性规划（LP）：所有输入均为已知常数，储能只受容量、接口功率与效率约束，不含预测误差与紧急购电，因此存在唯一的全局最优解。

按附件口径，一天被划分为 $N=144$ 个等长时段，$\Delta t=1/6$ 小时；附件中的时刻为时段终点，即 $00{:}10$ 表示 $00{:}00$--$00{:}10$，$0{:}00{+}1$ 表示 $23{:}50$--$24{:}00$。储能的充放电通过微网接口（PCS）与交流母线交换功率，附录给定的 $5000$ kW 最大充放电功率作用在接口侧，而非电池内部电量变化速率：充电时微网侧最多取电 $5000$ kW、电池侧电量最多增加 $5000\times0.9=4500$ kW；放电时微网侧最多供电 $5000$ kW、电池侧最多放出 $5000/0.9\approx 5555.56$ kW。

\subsection{模型建立}

\subsubsection{决策变量与参数}

对第 $t$ 个时段（$t=1,\dots,144$）定义决策变量：
\begin{itemize}
  \item $G_t$：计划购电量（kWh）；
  \item $c_t$、$d_t$：电池侧充电量、放电量（kWh）；
  \item $w_t$：弃光电量（kWh）；
  \item $E_t$：时段末储电量（kWh）。
\end{itemize}
模型参数：$\pi_t$ 为电价（元/kWh），$P^{\mathrm{load}}_t$ 为小区负载功率（kW），$P^{\mathrm{pv}}_t$ 为光伏发电预测功率（kW），$\eta=0.9$ 为储能充放电效率，$E_{\min}=1200$、$E_{\max}=10800$（kWh）为储电量上下限，$E_0=6000$ kWh 为 $0{:}00$ 初始储电量，$P_{\max}=5000$ kW 为微网接口最大充放电功率。

\subsubsection{目标函数}

以全天计划购电费用最小为目标：
\begin{equation}
\min \sum_{t=1}^{144}\pi_t G_t \label{eq:q1_obj}
\end{equation}

\subsubsection{约束条件}

\begin{enumerate}
  \item 电量平衡。每个时段外网购电、光伏发电与储能放电共同满足负载、储能充电与弃光：
  \begin{equation}
  G_t+P^{\mathrm{pv}}_t\Delta t+\eta d_t
  =P^{\mathrm{load}}_t\Delta t+\frac{c_t}{\eta}+w_t,\quad t=1,\dots,144 \label{eq:q1_balance}
  \end{equation}
  \item 储电量递推与日闭环。$E_0=E_{144}=6000$ 保证 $0{:}00$ 与 $24{:}00$ 储电量相同：
  \begin{equation}
  E_t=E_{t-1}+c_t-d_t,\qquad E_0=E_{144}=6000 \label{eq:q1_soc}
  \end{equation}
  \item 储电量范围，防止过充与过放：
  \begin{equation}
  E_{\min}\le E_t\le E_{\max} \label{eq:q1_soc_range}
  \end{equation}
  \item 微网接口功率上限。电池侧充电时交流侧取电 $c_t/\eta$，放电时交流侧供电 $\eta d_t$，二者均不得超过接口额定功率 $P_{\max}$：
  \begin{equation}
  0\le\frac{c_t}{\eta}\le P_{\max}\Delta t,\qquad
  0\le\eta d_t\le P_{\max}\Delta t \label{eq:q1_power}
  \end{equation}
  \item 非负约束：
  \begin{equation}
  G_t\ge 0,\quad c_t\ge 0,\quad d_t\ge 0,\quad w_t\ge 0 \label{eq:q1_nonneg}
  \end{equation}
\end{enumerate}

由式~\eqref{eq:q1_soc} 结合 $E_0=E_{144}$ 可知电池侧全天充放电量相等，即 $\sum_t c_t=\sum_t d_t$；因 $\eta<1$，交流侧放电量小于充电取电量，差额由多购电弥补。由于同一时段同时充放电只会引入效率损耗、增加购电，最优解中不会出现 $c_t d_t>0$。

\subsection{模型求解与结果}

模型为连续线性规划，使用 PuLP 调用 CBC 求解器，共 $5\times144=720$ 个连续变量与 $6\times144$ 个线性约束，求解器在秒级返回全局最优解（状态 Optimal）。当天负荷总电量为 $111024.81$ kWh，光伏总电量为 $55482.84$ kWh，净缺口为 $55541.97$ kWh。

最优策略下，全天计划购电量为 $59482.70$ kWh，全天购电费用为 $35126.95$ 元，$0{:}00$ 与 $24{:}00$ 储电量均为 $6000$ kWh，弃光为 $0$，接口最大充电功率达到 $5000$ kW、最大放电功率为 $4293.92$ kW。表~\ref{tab:q1_purchase} 给出题目指定时段的购电量及全天购电量和购电费，表~\ref{tab:q1_storage} 给出储能按 4 小时聚合的充放电量及起止储电量（表~\ref{tab:q1_storage} 中的充放电量为电池侧电量）。

\subsection{模型检验}

为验证模型有效性，设置两个对照模型：B0（无储能，$G_t=\max(P^{\mathrm{load}}_t-P^{\mathrm{pv}}_t,0)\Delta t$）和 B1（分时贪婪：低价尽量充电、高价尽量放电，再补净负荷）。三种模型的购电费用见表~\ref{tab:q1_baseline}。

M0 的购电费比无储能 B0 降低 $26.90\%$，比分时贪婪 B1 降低 $9.20\%$，且 M0 的购电量也最小、弃光为 $0$，说明储能的峰谷套利能够有效降低购电费用并实现光伏的完全消纳。进一步对最优解做可行性检查：各时段电量平衡残差小于 $10^{-3}$ kWh，储电量始终落在 $[1200,10800]$ kWh 内，$E_0=E_{144}=6000$，接口充放电功率不超过 $5000$ kW，且各时段不存在同时充放电，验证了模型与求解的正确性。
