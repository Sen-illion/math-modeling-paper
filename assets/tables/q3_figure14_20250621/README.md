## 画图时选哪些列

建议用共享横轴的三个面板：

1. **负载与光伏**：`plot_10min` 的 `hour_start` 作横轴，`load_kw`、`pv_kw` 作纵轴；需要展示供需缺口时加入 `net_load_kw`。
2. **购电与储能调度**：`hour_start` 作横轴，`planned_purchase_kw`、`adjusted_purchase_kw` 画阶梯线。充放电可用 `charge_kw`、`discharge_kw` 另画正负柱形；或使用 `storage_net_output_kw`（正值放电、负值充电）。
3. **储电量**：`soc_145_points` 的 `hour` 对 `soc_kwh` 画折线，并加入 `soc_min_kwh=1200`、`soc_max_kwh=10800` 两条水平线。

每个功率值对应 `[time_start, time_end)` 整个 10 分钟时段。绘制功率阶梯线时用这些时段边界，完整覆盖 00:00–24:00；储电量使用独立的 145 点表，恰好包含首末边界。图中可在 06:00、12:00、18:00 添加竖线表示日内调整时点。

### 单位与边界

- 后缀 `_kw` 为功率；后缀 `_kwh` 为电量或储电量。每段电量除以 1/6 h 得到平均功率，即乘以 6。
- 充放电采用微网接口侧口径：`soc_end = soc_start + 0.9 × charge_kwh − discharge_kwh / 0.9`。
- `soc_start_kwh`、`soc_end_kwh` 分别是同一时段的起点和终点储电量；相邻段连续。
- 官方模板一行从当天 00:10 开始，末列是次日 00:00–00:10。本数据已取**前一天末列**作为当天第 0 段，并拼入当天其余 143 段，转换为完整日历日。
- `plan_source_cell`、`adjusted_source_cell` 给出每段在 `result3.xlsx` 中的来源单元格。
- 费用为原始计划费、相对原始计划的调整增量费用及紧急购电费之和；调整增量可以为负。

## 哪些数据是直接记录，哪些是复算

负载、光伏和电价来自附件 1、2；144 段的计划与调整购电量直接取自正式 `results/Q3/result3.xlsx`。

官方工作簿只保存四小时充放电汇总与日初、日末储电量，未保存完整的逐 10 分钟储能轨迹。因此，充电、放电、弃光、紧急购电和逐时段储电量是：从官方日初储电量出发，以官方最终购电量为固定输入，按原 `code/Q3/simulate.py` 执行规则进行**确定性的逐段复算**。这部分并非从旧图读数或对汇总值插值，也没有重新优化购电方案。

复算结果已通过 19 项数值核对，包括计划费用、最终费用、日末储电量、紧急购电量、06:00 前合同一致性、各四小时充放电汇总、电量平衡和储电量递推；原执行规则的物理约束检查也通过。

## 复现

需要 Python、numpy、pandas 和 openpyxl，并保留建模仓库的附件、正式结果与 Q3 代码：

```text
python export_data.py --model-repo <建模仓库路径> --date 2025-06-21
```

脚本先检查附件与正式运行清单的哈希，再提取数据和复算；任一数值核对失败会报错，不生成新的数据表。`--output-dir` 可以指定独立输出目录。

本次数据整理使用 Codex 辅助编写提取程序并核对时间对齐、单位换算与官方结果；人工使用时可通过数据字典、来源单元格及核验工作表复查。
