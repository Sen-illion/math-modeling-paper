# 03｜提交前检查

## 官方格式要点

- A4 纸，上下左右页边距至少 2.5 cm；
- 纸质版第一页为承诺书，第二页为编号专用页，第三页为摘要；
- 正文从摘要页之后开始，正文不超过 30 页，正文不设目录；
- 电子版从摘要页开始，不包含承诺书和编号专用页；
- 电子版建议提交 PDF，正文、附录和支撑材料不得出现身份信息；
- 附录应列出支撑材料并提供完整、可运行的源程序；
- 使用 AI 时，在参考文献前保留真实的 AI 工具使用声明，并另附使用详情。

本目录中的 `cumcmthesis.cls` 保留了原模板的承诺书和编号页实现。电子版入口 `main.tex` 会排除这两页；纸质版使用 `main_print.tex` 前，应将其承诺书和编号页与当年官方专用页逐项核对，必要时以官方文件为准。

## 技术检查

- Overleaf 使用 XeLaTeX 编译无 error；
- 无 `undefined references`、`Citation ... undefined` 或字体错误；
- 图表、公式和章节编号连续；
- 所有图片清晰，表格不越界；
- 论文中的数字与结果文件、代码输出一致；
- 删除全部占位文本、示例图片、示例文献和模板说明。
- 检查 `paper/assets/` 中论文所用图表和参考资料是否已提交到 GitHub，并核对来源、版本和对应问题。

## 提交建议

先下载 PDF 并逐页检查，再将 PDF 与支撑材料压缩包分别提交。不要把承诺书和编号专用页放入电子版论文 PDF。
